# Business Sales Data Analysis & Visualization

## Project Overview

This project focuses on cleaning, analyzing, and visualizing business sales data using Python. It transforms raw sales data into a structured dataset and extracts meaningful business insights through statistical analysis and data visualization.

The project demonstrates practical data analysis skills using Pandas, NumPy, and Matplotlib.

## Features

- **Data Exploration:** Explore dataset structure, columns, data types, and statistical summaries.
- **Data Cleaning:** Handle missing values, remove duplicate records, and correct invalid data.
- **Data Transformation:** Convert numerical and date columns into appropriate data types.
- **Business Analysis:** Calculate total revenue, average sales, highest sales, lowest sales, and total quantity ordered.
- **Product Performance:** Identify the best-performing product line based on total revenue.
- **Data Visualization:** Generate a bar chart to compare sales across different product lines.
- **CSV Export:** Export the cleaned dataset for further analysis.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
